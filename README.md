# Coconut Client

Fabric client mod for Minecraft 1.21.11.

## Get the jar without installing anything
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (including the hidden `.github` folder).
3. Open the repo's **Actions** tab, click **Build Coconut Client**, wait for the green check.
4. Open the finished run and download the **coconut-client-jar** artifact (a zip containing the jar).

## Install
1. Install Fabric Loader for 1.21.11 from fabricmc.net/use.
2. Put `coconutclient-0.1.0.jar` and Fabric API (modrinth.com/mod/fabric-api) in your `.minecraft/mods` folder.
3. Start the Fabric 1.21.11 profile. Press Tab in-game for the module menu.
